# Limits 0.6.0

## Linux

Все проверки Linux-версии выполнялись на **Linux Mint 22.2 Zara, x64, XFCE 4.18 / X11**. Проверены запуск приложения, чтение настоящих лимитов Codex, переключение аккаунтов, значки в системном трее и окно подробностей. Все 62 автоматических теста и проверка запуска Electron прошли успешно. AppImage проверен обычным запуском, DEB — запуском распакованного приложения и проверкой зависимостей без установки в систему. Другие дистрибутивы и рабочие столы требуют отдельной проверки.

**В Linux виджет поддерживается в виде двух отдельных значков в системном трее** и имеет собственное оформление:

- `5h` — пятичасовой лимит с бирюзовым оформлением.
- `7d` — недельный лимит с фиолетовым оформлением.
- Светлые цифры показывают процент оставшегося лимита, короткая полоса снизу дополняет его визуально.
- Собственный тёмный фон, рамки и прозрачные отступы делают соседние значки различимыми на панели.
- При остатке не более 10% полоса становится красной; неизвестные или устаревшие данные отображаются приглушённо.

Эксклюзивное оформление Linux-индикаторов `5h` и `7d`:

![Отдельные индикаторы пятичасового и недельного лимитов в трее Linux](docs/screenshots/linux-tray.jpg)

**Время до сброса пятичасового лимита доступно при наведении** на значок `5h`. Подсказка также показывает точный процент, аккаунт и тариф. Таймер не занимает место внутри значка. Нажатие открывает подробности, правый клик — меню; обработка подсказок и кликов зависит от рабочего стола.

Окно подробностей подстраивает высоту под содержимое: снизу больше нет большой пустой зоны. Раскрытие настроек аккаунта увеличивает окно, закрытие уменьшает его. Длинный список аккаунтов прокручивается внутри окна.

### Запуск на Linux

Готовые пакеты находятся в папке `release`:

- `Limits-0.5.3-x86_64.AppImage` — запуск без установки.
- `Limits-0.5.3-amd64.deb` — пакет для установки через менеджер пакетов.

Для AppImage разрешите выполнение файла в его свойствах или выполните:

```sh
chmod +x Limits-0.5.3-x86_64.AppImage
./Limits-0.5.3-x86_64.AppImage
```

Готовое приложение не требует системного Node.js. Нужен установленный Codex CLI и вход через ChatGPT. Если CLI отсутствует в `PATH`, укажите его полный путь:

```sh
CODEX_LIMITS_CODEX_PATH='/полный/путь/к/codex' ./Limits-0.5.3-x86_64.AppImage
```

Автозапуск в Linux пока не реализован. Чтобы завершить приложение, выберите «Выйти из приложения» в меню значка.

## Windows

Доступны компактный виджет на панели задач и режим двух значков в системном трее. В виджете отображаются выбранный аккаунт, тариф, оба лимита и время до сброса пятичасового окна. Режим можно переключить в окне подробностей или через меню «Отображение»; выбор сохраняется.

Для Windows предусмотрены portable EXE и установщик для текущего пользователя. Все сборки включают компонент подключения и работают без отдельной установки Codex.

## macOS

На Mac доступны два варианта отображения. Выбор сохраняется при перезапуске и переключается в настройках или меню «Отображение».

### Две полоски в строке меню

- Отдельные индикаторы `5h` и `7d` показывают оставшийся процент и полосы лимитов.
- Рядом с `5h` видно время до сброса в формате `часы:минуты`. Таймер в строке меню обновляется локально каждые 15 секунд.
- Нажатие на любой индикатор открывает подробности под ним, правый клик — меню приложения.
- Изображения поддерживают Retina. Низкие, устаревшие и неизвестные значения различаются визуально.

Панель оформлена в стиле Liquid Glass: нативное размытие macOS, скругления, светлая и тёмная темы. При первом запуске она ждёт координат индикатора и открывается в правильном месте. Системное уменьшение прозрачности поддерживается.

### Чёлка · Apple

На Mac с **физической чёлкой** появляется дополнительный режим. На компьютерах без неё этот пункт скрыт.

- Наведение плавно раскрывает компактный просмотр обоих лимитов и времени до сброса `5h`.
- Нажатие раскрывает полную панель с аккаунтами, настройками и ручным обновлением.
- Esc, кнопка закрытия или уход фокуса сворачивают интерфейс к чёлке.
- Системное уменьшение движения отключает анимации.
- Если подключён внешний монитор, используется экран MacBook с чёлкой. При отключении этого экрана приложение возвращается к двум индикаторам.

Просмотр при наведении:

![Краткий просмотр лимитов и таймера при наведении на чёлку](docs/screenshots/apple-notch-hover.png)

Полная панель после нажатия:

![Панель Limits, раскрытая из чёлки MacBook](docs/screenshots/apple-notch-expanded.png)

Снимки подготовлены из интерфейса приложения с демонстрационными данными; фон и строка меню воссозданы как нейтральный рабочий стол для публикации.

Codex CLI автоматически находится внутри Codex.app/ChatGPT.app, Homebrew, nvm и пользовательских каталогов, включая запуск из Finder. Доступен запуск при входе в macOS. Для установки на Apple Silicon предусмотрены `Limits-0.6.0-arm64.dmg` и ZIP; исходники также поддерживают сборку для Intel.

Все Mac-функции, AppKit-помощник, стили и тесты находятся в [`src/apple_feature`](src/apple_feature/README.md). После объединения с Linux-изменениями на Mac прошли 73 автоматических теста и проверка обоих режимов в Electron. Проверка Linux Mint выше относится к Linux-сборке 0.5.3.

## Общие возможности

- Несколько аккаунтов с отдельными лимитами и выбором аккаунта для виджета.
- Локальные имена аккаунтов, русский и английский интерфейсы.
- Автоматическое обновление примерно каждые 30 секунд после завершения предыдущего запроса и кнопка ручного обновления.
- Отображение оставшегося процента и времени сброса по данным Codex.

Limits показывает лимиты **Codex по подписке ChatGPT**. Приложение читает данные через Codex CLI; оно не создаёт чаты и не отправляет запросы модели. Подробности запуска и сборки — в [README.md](README.md).
