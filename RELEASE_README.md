**Limits** — компактное настольное приложение, которое показывает оставшиеся лимиты **Codex по подписке ChatGPT**. Процент остатка, время до сброса и выбранный аккаунт доступны прямо на рабочем столе: можно оценить запас перед следующей задачей, не открывая Codex.

Сейчас приложение работает с Codex. Интеграции с другими сервисами запланированы в [будущих возможностях](#roadmap).

## Возможности

- **Два окна лимитов:** остаток пятичасового и недельного лимитов, время до сброса.
- **Несколько аккаунтов:** отдельные лимиты, локальные имена и выбор аккаунта для индикаторов.
- **Автоматическое обновление:** примерно каждые 30 секунд после предыдущего запроса, обновление после выхода из сна и ручная кнопка обновления.
- **Понятное состояние данных:** низкий остаток выделяется цветом, неизвестные значения показаны прочерком, устаревшие данные приглушены.
- **Русский и английский интерфейсы:** язык и настройки отображения сохраняются между запусками.

Limits читает данные о лимитах через Codex App Server. Приложение не создаёт чаты и не отправляет запросы модели. Для отображения лимитов подписки нужен **вход через ChatGPT**; авторизация API-ключом эти данные не предоставляет.

<a id="platforms"></a>

## Поддерживаемые системы

| Система | Архитектура готовых пакетов | Отображение | Нужен установленный Codex |
| --- | --- | --- | --- |
| Windows 10 / 11 | x64 | Виджет на панели задач или два значка в трее | Нет — компонент подключения включён в приложение |
| macOS | Apple Silicon (arm64), Intel (x64) | Два индикатора в строке меню; режим чёлки на совместимых MacBook | Да — приложение Codex или нативный Codex CLI |
| Linux | x64 | Два значка в системном трее | Да — нативный Codex CLI |

**Проверенное окружение Linux:** Linux Mint 22.2 Zara, XFCE 4.18, X11, x64. Другие дистрибутивы и рабочие столы требуют отдельной проверки; поведение трея зависит от окружения.

### Windows · виджет на панели задач

Компактный блок показывает аккаунт, тариф, оба лимита и время до сброса пятичасового окна. Его можно перетащить за область аккаунта и выбрать ширину: **240, 280, 320 или 400 px**. Положение сохраняется.

<p align="center">
  <img src="docs/screenshots/windows-widget.png" width="280" alt="Виджет Limits на панели задач Windows с демонстрационными лимитами">
</p>

Особенности Windows:

- Переключение между виджетом и двумя значками в трее.
- Виджет скрывается при полноэкранном приложении и восстанавливается после перезапуска панели задач.
- При остатке не более **10%** появляется уведомление — один раз за окно лимита.
- Автозапуск при входе в систему для установленной версии.
- Работа без отдельной установки Codex; если входа ещё нет, приложение открывает панель авторизации.

Виджет располагается поверх горизонтальной панели задач. Если он перекрывает кнопки приложений, переместите его в удобное место. Windows может сначала скрыть значки трея под стрелкой возле часов — их можно перетащить в видимую область.

### macOS · строка меню и чёлка

Два индикатора **5h** и **7d** показывают оставшиеся проценты и полосы лимитов. Рядом с пятичасовым индикатором отображается время до сброса; таймер в строке меню обновляется локально каждые 15 секунд.

![Светлая панель Limits и индикаторы в строке меню macOS](docs/screenshots/apple-menu-bar-light.png)

Особенности macOS:

- Нативное размытие панели в стиле Liquid Glass, светлая и тёмная темы, поддержка Retina.
- На MacBook с **физической чёлкой** — краткий просмотр по наведению и полная панель по нажатию.
- Режим чёлки использует экран MacBook, в том числе при подключённом внешнем мониторе; на Mac без чёлки этот режим скрыт.
- Поддержка системного уменьшения движения и прозрачности.
- Автозапуск при входе в macOS.

### Linux · два контрастных индикатора

В системном трее отображаются два отдельных блока: **5h** на бирюзовом фоне и **7d** на фиолетовом. Светлые цифры показывают остаток, короткая полоса дополняет его визуально.

![Индикаторы пятичасового и недельного лимитов в трее Linux](docs/screenshots/linux-tray.jpg)

Особенности Linux:

- Собственный фон и отступы помогают различать индикаторы при разных темах панели.
- Время до сброса пятичасового лимита, аккаунт и тариф доступны в подсказке при наведении.
- Высота окна подробностей подстраивается под содержимое; длинный список аккаунтов прокручивается.

Автозапуск Linux пока не реализован. Нажатия и подсказки значков обрабатываются с учётом возможностей рабочего стола.

*Снимки интерфейса Windows и macOS используют демонстрационные данные. На снимках macOS фон и строка меню воссозданы как нейтральный рабочий стол для публикации.*

<a id="installation"></a>

## Установка

Скачайте пакет для своей системы из [GitHub Releases](https://github.com/PyatkovVK/limits/releases). Сборки из `main` доступны в [предварительном релизе `latest`](https://github.com/PyatkovVK/limits/releases/tag/latest).

Готовые приложения содержат Electron и **не требуют установки Node.js**.

| Система | Пакеты версии 0.6.0 |
| --- | --- |
| Windows x64 | `Limits-Setup-0.6.0.exe` · `Limits-0.6.0-portable.exe` |
| macOS Apple Silicon | `Limits-0.6.0-arm64.dmg` · `Limits-0.6.0-arm64.zip` |
| macOS Intel | `Limits-0.6.0-x64.dmg` · `Limits-0.6.0-x64.zip` |
| Linux x64 | `Limits-0.6.0-x64.AppImage` · `Limits-0.6.0-x64.deb` |

### Windows

Запустите **Setup**, чтобы установить Limits для текущего пользователя, или откройте **portable EXE**, чтобы пользоваться без установки. Отдельный Codex не нужен.

Если вы уже вошли в Codex на этом компьютере, Limits использует существующий аккаунт. Иначе нажмите **«Войти через ChatGPT»** в открывшейся панели и завершите вход в браузере.

### macOS

Выберите пакет для своего процессора. Откройте **DMG** и перенесите Limits в **Applications**, либо распакуйте **ZIP** и переместите приложение туда.

Нужен установленный Codex: Limits автоматически ищет CLI внутри Codex.app / ChatGPT.app, а также в Homebrew, nvm и пользовательских каталогах. Если аккаунт ещё не подключён, откройте подробности и нажмите **«Войти через ChatGPT»**.

### Linux

Для запуска **AppImage** разрешите выполнение файла:

```sh
chmod +x Limits-0.6.0-x64.AppImage
./Limits-0.6.0-x64.AppImage
```

Для установки **DEB** на совместимом дистрибутиве:

```sh
sudo apt install ./Limits-0.6.0-x64.deb
```

Codex CLI должен быть доступен в `PATH` приложения. Если он установлен в другом месте, укажите абсолютный путь:

```sh
CODEX_LIMITS_CODEX_PATH='/absolute/path/to/codex' ./Limits-0.6.0-x64.AppImage
```

Используйте существующий вход Codex или откройте подробности и нажмите **«Войти через ChatGPT»**.

<a id="usage"></a>

## Как пользоваться

1. **Запустите Limits и подключите аккаунт.** Уже сохранённая авторизация Codex подхватывается автоматически.
2. **Откройте подробности**, нажав на виджет или индикатор. Здесь видны лимиты, тариф и состояние обновления.
3. **Добавьте другие аккаунты** через **«Аккаунты» → «+ Добавить»** и завершите вход в браузере.
4. **Выберите «В виджет»** у нужного аккаунта. Его лимиты появятся в компактном отображении.
5. **Настройте приложение:** задайте локальное имя в **«Имя и подключение»**, выберите язык и доступный режим отображения.

Основной аккаунт использует общее хранилище авторизации Codex (`CODEX_HOME`). Смена этого аккаунта в Limits также меняет аккаунт CLI, использующего то же хранилище. Добавленные через **«+ Добавить»** аккаунты хранятся отдельно и не меняют основной вход Codex.

Данные обновляются автоматически. При необходимости нажмите кнопку ручного обновления. После ошибок интервал опроса постепенно увеличивается до пяти минут; неизвестные или устаревшие значения отличаются от актуальных. Если сервис не предоставляет одно из окон лимита, приложение показывает прочерк.

Закрытие окна подробностей оставляет Limits работающим. Для завершения выберите **«Выйти из приложения»** в меню виджета или значка. Перед запуском новой версии завершите старую.

## Запуск из репозитория

Для работы с исходниками нужны **Git**, **Node.js 22.12+** и npm. Дополнительные требования зависят от ОС:

| Система | Требования |
| --- | --- |
| Windows x64 | .NET Framework 4.x; помощник собирается встроенным компилятором Windows, .NET SDK не нужен |
| macOS | Xcode Command Line Tools для сборки нативного помощника: `xcode-select --install` |
| Linux | Графическое окружение с системным треем |

Для настоящих лимитов на macOS и Linux нужен установленный Codex. Для просмотра интерфейса без входа используйте демонстрационный режим.

```sh
git clone https://github.com/PyatkovVK/limits.git
cd limits
npm install
npm start
```

В PowerShell, если политика выполнения блокирует `npm.ps1`, используйте **`npm.cmd`** вместо `npm`. При переносе проекта на другую ОС установите зависимости заново, не копируйте `node_modules`.

| Команда | Назначение |
| --- | --- |
| `npm run demo` | Интерфейс с явно отмеченными демонстрационными данными, без авторизации |
| `npm test` | Общие тесты и тесты всех платформ с подменой системных зависимостей |
| `npm run doctor` | Диагностика настоящего подключения к Codex |
| `npm run smoke` | Проверка запуска Electron и интерфейса с демонстрационными данными |
| `npm run smoke:live` | Проверка интерфейса с настоящим аккаунтом; нужен вход через ChatGPT |
| `npm run smoke:onboarding` | Проверка первого входа с пустым хранилищем; только Windows |

Автоматические тесты можно запускать на любой из поддерживаемых ОС: файловая система и платформенные API подменяются. Проверки настоящего интерфейса выполняются на целевой ОС.

Общий код находится в [`src/common`](src/common), платформенные функции — в [`src/windows_feature`](src/windows_feature), [`src/apple_feature`](src/apple_feature) и [`src/linux_feature`](src/linux_feature).

<a id="build"></a>

## Сборка

Собирайте приложение **на той системе, для которой нужен пакет**. Перед первой сборкой выполните `npm install`.

| Где выполнять | Команда | Результат |
| --- | --- | --- |
| Windows x64 | `npm run build:win` | Portable EXE и установщик NSIS; компонент Codex включён |
| macOS | `npm run build:mac -- --arm64` | DMG и ZIP для Apple Silicon |
| macOS | `npm run build:mac -- --x64` | DMG и ZIP для Intel |
| Linux x64 | `npm run build:linux` | AppImage и DEB |

Если архитектура не указана, macOS и Linux собираются под архитектуру текущего Node.js. Для Linux также доступны параметры `--x64` и `--arm64`; готовые релизные пакеты публикуются для x64.

Готовые пакеты появляются в **`release/`**. Локальная сборка ничего не публикует. Большие промежуточные файлы создаются во временной папке ОС; на её диске нужно около 2 ГБ свободного места. Переменная `CODEX_LIMITS_KEEP_BUILD=1` сохраняет распакованную сборку для диагностики.

Локальные сборки macOS без сертификата используют подпись ad hoc; подпись Developer ID и нотариализация настраиваются отдельно. Windows-пакеты не подписаны сертификатом разработчика.

В [GitHub Actions](.github/workflows/release.yml) полный набор тестов выполняется на Windows, macOS Apple Silicon, macOS Intel и Linux. Релиз публикуется после успешных проверок и сборок всех вариантов; вместе с пакетами создаётся `SHA256SUMS.txt`.
