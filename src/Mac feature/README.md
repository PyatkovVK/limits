# macOS

В этой папке находится поведение, специфичное для Mac:

- `codex-path.cjs` — поиск CLI внутри Codex.app и ChatGPT.app, в `/Applications` и `~/Applications`, а также в Homebrew, nvm и пользовательских каталогах CLI. Работает при запуске из Finder без терминального PATH.
- `panel.cjs` и `renderer/style.css` — прозрачная панель с нативным vibrancy, скруглениями и оформлением в стиле Liquid Glass. При первом запуске ждёт координаты индикатора и открывается под ним. Клик привязывает панель к выбранному индикатору и его монитору; если координаты недоступны, панель открывается сверху справа. Поддерживает светлую/тёмную тему и системное уменьшение прозрачности. Использует стандартный API Electron для размытия; не добавляет нативный NSGlassEffectView.
- `tray-icon.cjs` — два широких индикатора в строке меню: `5h` и `7d`, проценты и полосы оставшегося лимита. Есть изображения для Retina, состояния без данных и устаревших данных.
- `scripts/build-config.cjs` — локальная подпись ad hoc по умолчанию. Для подписи сертификатом укажите `CSC_NAME` или `CSC_LINK`; нотариализация требует отдельной настройки.
- `test/` — проверки поиска Codex, изображений индикаторов и позиции панели при первом запуске, задержке координат и работе с несколькими мониторами.

Общая точка входа: `npm run build:mac`. Сборка для Apple Silicon: `npm run build:mac -- --arm64`, для Intel: `npm run build:mac -- --x64`. Файлы появляются в `release`.

Клик по любому индикатору открывает панель. Правый клик открывает меню. Данные берутся у выбранного аккаунта, как в Windows.
