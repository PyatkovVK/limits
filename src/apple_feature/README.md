# apple_feature · macOS

Вся поддержка Mac находится в этой папке: поиск Codex, оформление и расположение панели, индикаторы, режим чёлки, сборка и проверки.

## Отображение

По умолчанию работают две полоски в строке меню: `5h` и `7d`, проценты и остаток лимита. Рядом с `5h` показано время до сброса (`часы:минуты`), которое обновляется каждые 15 секунд независимо от опроса сервера. Если сервер не передал время, показывается `—`; после истечения — `0:00` до получения новых данных. Клик открывает панель под выбранным индикатором, правый клик — меню.

На Mac с физической чёлкой в настройках «Отображение» и в контекстном меню появляется режим «Чёлка · Apple». Наведение раскрывает краткий просмотр двух лимитов и таймера, нажатие открывает полную панель. Esc, кнопка закрытия или уход фокуса сворачивают её обратно. Выбранный режим сохраняется при перезапуске. Системная настройка уменьшения движения отключает анимацию.

На Mac без чёлки этот режим скрыт и дополнительное окно не создаётся. При нескольких экранах чёлка располагается на экране MacBook, даже если основной монитор внешний. Если этот экран отключается, приложение возвращается к двум полоскам. Развёрнутый интерфейс доступен в разных Spaces и поверх полноэкранных приложений. Прозрачная область окна пропускает клики.

## Код

- `codex-path.cjs` — поиск CLI в Codex.app/ChatGPT.app, Homebrew, nvm и пользовательских каталогах при запуске из Finder.
- `panel.cjs`, `renderer/style.css` — панель с нативным vibrancy, светлой/тёмной темами и уменьшением прозрачности. Первая позиция ждёт координат строки меню.
- `menu-image.cjs`, `tray-icon.cjs` — Retina-индикаторы и таймер `5h`.
- `native/screen-info.m`, `screens.cjs` — небольшой универсальный AppKit-помощник. Чёлка определяется по `NSScreen.safeAreaInsets` и `auxiliaryTopLeftArea`/`auxiliaryTopRightArea`, без догадок по модели компьютера и без записи экрана.
- `geometry.cjs`, `notch.cjs`, `renderer/notch.js` — привязка к физической чёлке, наведение, обработка кликов и плавное раскрытие интерфейса.
- `i18n.js` — русские и английские строки macOS.
- `scripts/` — сборка универсального помощника и настройка локальной подписи ad hoc.
- `test/`, `smoke.cjs` — проверки поиска Codex, позиции, экранов, таймера, режимов и интерфейса.

## Сборка и проверка

`npm run build:mac` создаёт DMG и ZIP в `release`. Доступны `-- --arm64` и `-- --x64`. Для сборки AppKit-помощника нужны Xcode Command Line Tools (`xcode-select --install`); установленному приложению инструменты разработки не нужны.

`npm test` проверяет логику. `npm run smoke` запускает приложение с демонстрационными данными, проверяет оба режима на текущем Mac и сохраняет снимки в `artifacts`. `npm run smoke:live` проверяет установленный Codex.

`electron src/apple_feature/scripts/release-screenshots.cjs` создаёт снимки для `RELEASE_README.md` в `docs/screenshots`. Использует DOM и стили приложения, демонстрационные данные и нейтральный рабочий стол; личный рабочий стол и авторизация не считываются.

Для подписи сертификатом укажите `CSC_NAME` или `CSC_LINK`; нотариализация настраивается отдельно. Стеклянная панель использует стандартный Electron vibrancy.
