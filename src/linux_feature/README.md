# Linux

`panel.cjs` управляет высотой окна подробностей и его положением над панелью.
`renderer/panel.js` измеряет содержимое и сообщает высоту через проверенный IPC;
наблюдение учитывает обновление аккаунтов, смену языка и раскрытие настроек.
`renderer/style.css` сохраняет ширину текста при появлении полосы прокрутки.

Окно подстраивается под содержимое до 590 px и доступной высоты экрана. Более
длинный список прокручивается внутри окна. При изменении высоты открытой панели
нижний край сохраняет положение; при открытии из трея окно располагается внизу
справа в рабочей области монитора.

`tray-icon.cjs` рисует отдельные цветные значки `5h` и `7d`. Общий контроллер трея
находится в `src/windows_feature/tray.cjs`, мониторинг и авторизация — в `src`.

`npm test` включает `test/*.test.cjs` из этой папки. Проверка GUI выполняется
`npm run smoke` и `npm run smoke:live`. На целевой системе проверены Linux Mint
22.2, XFCE 4.18 и X11.
