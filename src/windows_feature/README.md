# windows_feature

Здесь находятся функции приложения для Windows:

- `widget.cjs` — окно блока на панели задач и восстановление после пересоздания Explorer.
- `taskbar.cjs` — геометрия блока, запуск и восстановление Win32-помощника.
- `tray-icon.cjs` — проценты и полосы в значках 16–48 px без дополнительных зависимостей.
- `renderer/` — компактный блок аккаунта и двух лимитов.
- `native/` — Windows C# помощник и завершающая страница установщика NSIS.
- `scripts/` — сборка Windows EXE, ICO и опциональной версии с Codex CLI.
- `test/` — тесты геометрии, перезапуска помощника, изображений и жизненного цикла значков.

Команды запускаются из корня проекта: `npm.cmd test`, `npm.cmd run smoke`, `npm.cmd run build:win`.

`src/common/main.cjs` соединяет эти функции с общим окном подробностей, монитором лимитов и сохранёнными настройками. Общий контроллер трея (`src/common/tray.cjs`) переключает один служебный значок на два значка лимитов, управляет подсказками и кликами. Данные аккаунта и OAuth находятся в общей интеграции Codex в `src/common`.
