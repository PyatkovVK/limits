# Проверки на macOS и Linux

На целевой ОС установите зависимости через `npm install` и запускайте smoke из графической сессии. Скриншоты и отчёты сохраняются в `artifacts/`.

## macOS

- [ ] Запустить `npm run test:mac` и `npm run test:mac:smoke`. Проверить индикаторы в строке меню, позицию панели после повторного открытия и три варианта макета notch. Если macOS запросит доступ к «Связке ключей», подтвердить его для проверки хранения тестовых ключей.
- [ ] На Mac с физическим вырезом после `npm run prepare:app` выполнить `npx --no-install electron test/smoke/apple-notch.cjs`. Проверить поведение при нехватке места в строке меню и прозрачные области вокруг выреза.

## Linux

- [ ] Запустить `npm run test:linux` и `npm run test:linux:smoke` в графической сессии с системным треем и разблокированной связкой ключей. Начать с XFCE/X11. Проверить оба стиля трея, открытие панели с верхней и нижней панелей, сохранение позиции и зашифрованное хранение тестовых ключей.
- [ ] Повторить проверку трея и позиции панели в доступной сессии Wayland. Зафиксировать окружение и поведение, если рабочий стол ограничивает позиционирование окон.
