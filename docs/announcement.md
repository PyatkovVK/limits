## English

**Limits: keep your Codex usage limits in sight**

I built Limits, an open-source desktop app that shows your remaining Codex subscription usage and reset times directly in the Windows taskbar, macOS menu bar, or Linux system tray.

It supports multiple accounts, automatic refresh, and English / Russian UI. Windows includes the Codex connection component; macOS and Linux use your installed Codex. Compatible MacBooks also have a notch view.

I'd appreciate testing on different desktops, especially Linux. If you try it, please share your OS, desktop environment, and any issues you encounter.

Source: https://github.com/PyatkovVK/limits

Downloads: https://github.com/PyatkovVK/limits/releases

Independent community project; not affiliated with or endorsed by OpenAI.

## Русский

**Limits: лимиты Codex прямо в панели задач**

Сделал Limits — открытое настольное приложение, которое показывает остаток лимитов Codex по подписке ChatGPT и время сброса прямо в панели задач Windows, строке меню macOS или системном трее Linux.

Есть несколько аккаунтов, автоматическое обновление, русский и английский интерфейсы. В Windows компонент подключения Codex уже включён; на macOS и Linux используется установленный Codex. На совместимых MacBook доступен режим чёлки.

Буду рад проверке на разных системах, особенно Linux. Если попробуете, напишите вашу ОС, рабочий стол и проблемы, с которыми столкнулись.
