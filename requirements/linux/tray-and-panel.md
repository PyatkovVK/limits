# Linux: system-tray indicators

| ID | Requirement | Acceptance criterion |
| --- | --- | --- |
| LIN-UI-001 | Display two independent limit indicators. | The five-hour indicator is turquoise and the weekly indicator purple; both refer to the selected common profile. |
| LIN-UI-002 | Retain the classic percentage style as the default. | A new profile or existing setting without an explicit choice uses classic, preserving the earlier colored badges. |
| LIN-UI-003 | Provide a bar style with the period label above the remaining bar. | English shows `5h`/`7d` and Russian `5ч`/`7д`; bar fill is proportional to the confirmed remainder. |
| LIN-UI-004 | Distinguish missing data, zero, full allowance, and stale data. | Unknown values use a dashed bar in bar style; 0% does not look unknown and 100% fills the bar; stale/low values have distinct styling. |
| LIN-UI-005 | Switch presentation through Settings → Display. | Changes apply immediately to both existing indicators, persist after restart, and do not unnecessarily recreate tray objects. |
| LIN-UI-006 | Keep indicators readable across tray themes and sizes. | Images have square canvases and scale representations; classic uses its own surface so numbers/bars do not merge with the panel background. |
| LIN-UI-007 | Provide tooltips and details activation where supported by the desktop. | Tooltips include account, remainder, and reset; supported clicks open the selected account’s details. |
| LIN-UI-008 | Toggle account details through quota indicators and the desktop widget. | Clicking either quota indicator or the widget's quota area opens hidden details and closes already visible details, including when the other quota indicator opened them. Explicit Details and Settings menu commands still open their targets. |
| LIN-UI-009 | Toggle the desktop widget through its application tray icon. | In desktop-widget mode, clicking the Limits tray icon hides the visible widget and details; another click restores only the widget without opening details. Persist widget visibility and retain the display mode, dimensions and saved position. |
| LIN-UI-010 | Keep the Linux presentation stable during polling. | Starting or finishing an ordinary usage refresh does not replace or reattach unchanged tray menus, recreate indicators, or hide/show an already visible desktop widget. Only changed quota pixels, tooltip text or menu content are updated; concurrent Refresh commands reuse the active request. Initial account announcements from a reconnected server retain the last sample until account/read confirms identity. A confirmed account switch or logout clears the previous account’s quotas before displaying new data. |
| LIN-UI-011 | Present three Linux display choices in one selector. | Settings → Display lists exactly (1) classic percentage tray icons, (2) period/bar tray icons, (3) desktop widget. Selecting a tray style immediately enters tray mode and updates both existing quota indicators without unnecessary recreation. Selecting the widget restores its saved placement. Persist the choice and migrate existing displayMode/linuxTrayStyle preferences without changing the selected presentation. |
